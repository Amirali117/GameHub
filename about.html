About & Guide.

The purpose, current status, and membership details of the GAME HUB launcher.

About GAME HUB

GAME HUB is an early-stage cloud-gaming launcher interface designed to organize supported titles and connect players to remote game sessions from one place. Actual streaming depends on a working cloud host/session link; the website itself does not host or stream game instances.

گیم‌هاب یک پروژه لانچر بازی در مرحله اولیه است که هدف آن جمع‌آوری بازی‌های منتخب در یک محیط ساده و دسترس‌پذیر و بهترکردن تجربه کاربران است.

Launcher goals

Our goal is to expand the game library, improve the launcher interface, make game access clearer, and introduce account and membership features as the project matures. Not every title is guaranteed to work on every device or network.

هدف لانچر گسترش فهرست بازی‌ها، بهترشدن رابط کاربری، ساده‌ترشدن دسترسی به بازی‌ها و اضافه‌شدن امکانات حساب کاربری در نسخه‌های آینده است.

Launcher updates

GAME HUB is currently in BETA 2.0. The interface is experimental; bugs, outages, unstable sessions, and an incomplete game list may occur. Actual cloud gameplay depends on the availability of each configured session and compatible network conditions.

لانچر در نسخه بتا قرار دارد. ممکن است باگ، اختلال، ناپایداری در اجرای بازی‌ها یا تغییراتی در امکانات وجود داشته باشد. فهرست بازی‌ها هنوز کامل نیست و در به‌روزرسانی‌های بعدی گسترش پیدا می‌کند.

VIP membership

VIP is a membership that users may purchase to access the launcher’s planned premium features and support. The intended benefits include access to all available launcher features and 24/7 support, subject to actual availability and service conditions.

اشتراک VIP عضویتی است که کاربر خریداری می‌کند تا از امکانات لانچر به‌همراه پشتیبانی ۲۴ ساعته بهره‌مند شود. این خدمات به‌تدریج توسعه داده می‌شوند و در دوره بتا ممکن است همه امکانات همیشه در دسترس نباشند.

Network and IP requirements

Some games or game sessions may require an IP address change or may not work with an Iranian IP address. Network restrictions, regional availability, and third-party services can affect whether a game starts successfully. GAME HUB cannot guarantee availability for every region.

بعضی بازی‌ها برای اجراشدن ممکن است به تغییر IP نیاز داشته باشند و با IP ایران اجرا نشوند. محدودیت‌های شبکه، منطقه جغرافیایی و سرویس‌های جانبی می‌توانند روی اجرای بازی اثر بگذارند.

How to use the launcher

  • Open the launcher and choose a game from the library.
  • Check the game status and press Play when a valid session is configured.
  • If a title does not open, the session may be unavailable or may require a compatible network.
  • Use the Profile page to manage your local profile and enter a VIP code.

بازی را از فهرست انتخاب کنید و در صورت فعال‌بودن لینک اجرای معتبر، روی دکمه اجرا بزنید. اگر بازی باز نشد، ممکن است نشست آن فعال نباشد یا به شبکه سازگار نیاز داشته باشد.

Important beta notice: GAME HUB is an early version. Bugs, downtime, unstable game sessions, incomplete game listings, and compatibility issues may occur. Please do not assume that every listed game is currently playable.
